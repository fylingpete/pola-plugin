# Profile: calendar (`calendar`)

Live run: Google Calendar (2026-09-20). Outlook uses the same rules.

The calendar is **not imported into pages**. An appointment proves no conversation, and a page per appointment floods the inbox and every person and company page. The tool keeps the calendar as a mirror instead (`calendar store`: one file in the brain's working folder, 90 days back and 14 ahead, refreshed, never growing), and the pola-meeting-prep skill reads it. When the user asks to import, connect or sync their calendar, run that skill.

- **What an event proves.** That an appointment existed. Not that anyone attended and not that a conversation took place. No page, no source, no timeline entry and no `last_contact` from a calendar entry; the tool refuses calendar entries as sources and `import plan` refuses this profile.
- **Later evidence.** A meeting page comes from a transcript, notes or the user's word. When one is written, the mirror can give its time and the invited people: same day or one day off, at least half the same people, a similar title.
- **Skipped by the tool.** Rooms, declined, all-day, cancelled and appointments without anyone else.
